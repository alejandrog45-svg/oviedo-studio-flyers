## Reglas estrictas de originalidad (pegar en Flow)
1. Usar únicamente las imágenes adjuntas (fachada, logos, productos). Si falta alguna, pedirla; no inventarla.
2. Logo Oviedo / Red MTS intocable: no redibujar, recolorear, recortar ni reescribir letras.
3. Fachada, patio, caseta, carpas, señalética y letreros: no regenerar, no mover, no añadir ni quitar elementos.
4. No inventar productos, marcas, envases, personas, vehículos, precios, SKU, descuentos ni fechas.
5. Marcas de terceros (Ceresita, Weber, Schneider, etc.) solo si aparecen en fotos originales adjuntas, sin retocar.
6. Textos exactos tal como se entregan; no corregir, traducir ni agregar texto. Montserrat.
7. Solo El Manzano; no mencionar otras sucursales.
8. Sin líneas grises ni bordes sueltos. Paleta rojo/negro/blanco.
9. Entregar como PROPUESTA pendiente de revisión humana; no publicar.

## Flujo
1. Editor → "Preparar instrucciones" → copiar a Flow (herramienta Oviedo Puente Flow, enlace en ESTADO_SESION).
2. Subir a la Biblioteca de Flow solo copias de fachada/logos (nunca originales).
3. Una prueba con Banana, **solo con créditos autorizados**.
4. Importar resultado al editor ("Importar imagen de Flow": queda marcado autenticidad pendiente).
5. Revisión humana con la lista QA; si falla alguna regla, se descarta.

otra sucursal · líneas grises · texto cortado o ilegible · sin aprobación humana.
